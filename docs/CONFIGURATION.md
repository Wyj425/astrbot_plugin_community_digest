# 配置说明

只在插件自己的配置页填写。不要把真实配置提交到 GitHub。

| 设置 | 默认值 | 说明 |
|---|---|---|
| `enabled` | false | 启用群聊与私聊精选推送。每会话每时段一张卡片和一句短评。 |
| `platform_id` | "" | QQ平台ID。群聊默认参与，私聊只推送明确配置的订阅者。 首次安装请填写当前 AstrBot 中实际配置的接入或提供商 ID。 |
| `schedule_mode` | "随机时间" | 推送时间模式（北京时间）。随机时间每天按会话生成并持久化，重启不重抽、不补发已错过时段。 |
| `daily_count` | 2 | 每会话每天最多几条内容，1至6。固定时间模式只取前N个时间。 |
| `random_start` | "09:00" | 随机时间窗口起点，HH:MM。 |
| `random_end` | "24:00" | 随机时间窗口终点，不包含此时刻；可用24:00。 |
| `min_gap_minutes` | 90 | 同一个会话两次随机推送之间至少间隔多少分钟。 |
| `fixed_times` | ["12:30", "20:30"] | 固定时间列表，例如12:30、20:30。仅固定时间模式生效。 |
| `default_keywords` | ["Apex", "英雄联盟", "游戏趣事"] | 旧版默认关键词，未填默认订阅标签时使用。建议使用默认订阅标签。 |
| `min_score` | 80 | 推送最低分，0至100。相关性40＋信息质量25＋趣味性20＋时效性15。低于门槛就不推送。 |
| `selection_mode` | "最高分" | 从所有可用平台的合格候选中只选一条，不会三平台各发一条。 |
| `cache_ttl_days` | 3 | 候选缓存保留天数，1至30。从首次入库起算，重复检索不延长；到期自动删除。 |
| `published_max_age_days` | 7 | 允许推送的内容发布年龄上限，1至90天。实际过期时间取发布有效期和缓存期限中较早者。未知发布时间会扣时效分。 |
| `refresh_cooldown_minutes` | 180 | 同一标签、同一平台无合格库存时，两次检索至少间隔多少分钟。相同标签跨群聊和私聊共享冷却与候选。 |
| `keywords_per_refresh` | 2 | 无合格库存时每轮选择几个订阅标签，1至3。每个标签的平台检索、评分供所有订阅者共享。 |
| `comment_mode` | "人设短评" | 卡片后的一句话。人设短评优先读字幕或正文；引用热门评论会标明来源，取不到短热评时使用人设短评。混合模式约30%优先引用。 |
| `group_rules` | [] | 群聊订阅。按群选择共享标签、平台、频率、门槛及人设；未列出的群沿用全局。 |
| `xhs_enabled` | false | 启用已登录的小红书关键词搜索及正文读取。 |
| `heybox_enabled` | false | 启用已登录的小黑盒，按关键词匹配真实游戏分区，无匹配分区时筛选推荐流。 |
| `source_in_title` | true | 签名前为小红书标题加【小红书】；B站继续用已验证的其他来源图文卡。 |
| `provider_id` | "" | 评分和短评使用的模型提供商。每次检索批量评分一次，每次推送人设短评至多调用一次；命中缓存不重复评分。 首次安装请填写当前 AstrBot 中实际配置的接入或提供商 ID。 |
| `model_daily_call_limit` | 12 | 本插件每天模型调用总上限，包括兴趣分析、候选评分及短评。达到上限时保持已有兴趣和缓存，短评用本地句子，不为未评分内容放行。 |
| `tag_library` | [] | 共享标签库。订阅者填写标签名称即可；同一标签的检索和评分全局复用。别名用于将 LOL、英雄联盟等写法归并到同一个标签。 |
| `default_tags` | ["Apex", "英雄联盟", "游戏趣事"] | 没有单独配置的群、以及未填写标签的已订阅私聊使用这些标签。填写共享标签库中的名称。 |
| `private_rules` | [] | 私聊订阅。添加QQ号并选择标签；与群聊共享检索和候选，每个私聊独立计数、去重。不会自动给全部好友推送。 |
| `interest_enabled` | false | 结合本会话最近聊天与LivingMemory记忆识别近期兴趣，自动订阅共享标签。每天最多一条推送优先匹配近期兴趣；其他从固定兴趣选择，同主题每天最多一条。 |
| `interest_window_hours` | 72 | 分析最近多少小时的真实聊天，建议72；只读取当前群聊或私聊，排除机器人消息。 |
| `interest_ttl_days` | 3 | 近期兴趣有效天数，默认3。从引用的最后一条真实讨论起算；没有新证据不会自动续期。每会话最多3个近期兴趣。 |
| `interest_daily_call_limit` | 4 | 全插件每天最多几次兴趣分析调用，默认4。每会话每天最多1次；无新增聊天或消息不足时跳过。也受原有模型总调用上限限制，0表示暂停新分析。 |
| `interest_excluded_sender_ids` | [] | 额外排除的机器人QQ号。当前机器人会自动排除；如群里还有其他机器人，可在此填写QQ号。 |
| `extended_reasoning_compat` | false | 部分OpenAI兼容网关需要额外的关闭推理字段；仅在服务支持时开启 |
